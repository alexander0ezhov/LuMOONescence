# LuMOONescence (fork of Moonlight for Android)

Клиент для стриминга игр с ПК на Android. Это **форк** [Moonlight for Android](https://github.com/moonlight-stream/moonlight-android)
с доработанным экранным управлением.

> Это не официальная сборка Moonlight. Имя и логотип Moonlight принадлежат проекту Moonlight
> и здесь не используются как имя продукта.

## Что добавлено в форке

- **Полноэкранный редактор раскладки**: плавающая шторка настроек, без панели, закрывающей экран.
- **Наборы раскладок**: свой набор кнопок на каждую игру, переключение без переподключения.
- **Экспорт и импорт раскладок** файлом (JSON) с пропорциональным пересчётом под экран другого устройства.
- **Меню трансляции** по кнопке «назад»: режимы касаний, прозрачность, выбор раскладки, клавиатура, выход.
- **Тачпад** в трёх видах: обычный, «курсор за пальцем» и без кликов; зажатие ЛКМ, ПКМ двумя пальцами.
- **Сквозной нажим**: зажал кнопку — стреляешь и одновременно водишь пальцем (обзор), как на геймпаде.
- **Предустановленная раскладка**, оформленная под 24 контрола.

## Сторонние сервисы

Часть возможностей по умолчанию использует **публичную инфраструктуру проекта Moonlight**:

- `stun.moonlight-stream.org:3478` — STUN-сервер, определяет внешний адрес для стриминга через интернет;
- `android.conntest.moonlight-stream.org` — сервис проверки сети при подключении.

Юридических ограничений на их использование нет (это открытые публичные сервисы), но это чужая
инфраструктура: она может быть ограничена или отключена без предупреждения. Если форк станет
популярным, стоит поднять свои аналоги — оба адреса задаются в двух местах:
`ComputerManagerService` (STUN) и `ServerHelper` (проверка сети).

## Сборка

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat :app:assembleNonRootRelease
```

Готовый APK: `app/build/outputs/apk/nonRoot/release/`, подписывается своим ключом
(Android Studio: *Build → Generate Signed App Bundle / APK → APK*).

Имя приложения и идентификатор задаются в `app/build.gradle` (`app_label`, `applicationId`).
