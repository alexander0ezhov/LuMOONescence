# План разработки системы удаленного управления и лауаут-менеджера (Moonlight)

**Цель:** Превратить примитивное экранное управление в полноценный, удобный инструмент с поддержкой клавиатуры/мыши и системой редактирования пользовательских раскладок.

---

## 🚀 Обзор изменений
1.  **Улучшение ввода:** Полная поддержка событий клавиатуры (кейкод) и мыши (координаты, кнопки).
2.  **Система лауаутов:** Создание централизованного менеджера для сохранения, загрузки и редактирования пользовательских раскладок контроллеров.
3.  **UX/UI:** Внедрение невидимого меню управления (доступного через "Назад" на Android TV), которое позволяет переключать режимы ввода и выбирать лауауты без отвлечения внимания пользователя во время сеанса.

---

## 🗺️ Пошаговый план действий

### Фаза 1: Улучшение обработки ввода (Input Handling)
**Цель:** Обеспечить, чтобы приложение корректно получало и обрабатывало все типы входных данных (клавиатура, мышь, сенсор).

1.  **Интеграция клавиатуры:**
    *   Проверить `KeyboardTranslator` и связанные классы для обеспечения максимальной совместимости с Android KeyCodes.
    *   Реализовать обработчик событий нажатия/отпускания клавиш в основном цикле ввода, который будет передавать данные на уровень контроллера (например, через `ControllerPacket`).
2.  **Интеграция мыши:**
    *   Убедиться, что все события движения и кликов мыши корректно преобразуются в пакеты данных для удаленного ПК.
3.  **Единый обработчик ввода (Input Dispatcher):**
    *   Создать центральный класс/механизм, который принимает сырые данные от Android Input System (KeyEvents, MotionEvents) и маршрутизирует их к соответствующему пакету (`ControllerPacket`, `KeyboardPacket`, `MouseButtonPacket`).

### Фаза 2: Архитектура управления лауаутами (Layout Management Core)
**Цель:** Создать основу для сохранения и применения различных конфигураций расположения элементов управления.

1.  **Модель данных Лауаута:** Определить класс/структуру `LayoutConfiguration`, который будет хранить:
    *   Имя лауаута (String).
    *   Список активных виджетов контроллера (например, "Кнопка A", "Стрелка Вверх").
    *   Позиции и размеры этих виджетов.
2.  **Менеджер Лауаутов (`LayoutManager`):**
    *   Отвечает за загрузку/сохранение списка доступных лауаутов (используя `SharedPreferences` или базу данных).
    *   Предоставляет методы: `loadDefaultLayout()`, `saveCurrentLayout(name)`, `getAvailableLayouts()`.
3.  **Применение Лауаута:** Изменить логику отрисовки контроллера так, чтобы она брала координаты и размеры из активного объекта `LayoutConfiguration` вместо жестко заданных значений.

### Фаза 3: Пользовательский интерфейс (UI/UX)
**Цель:** Создать удобный интерфейс для работы с лауаутами и переключения режимов ввода во время сеанса.

1.  **Экран Редактирования Лауаута (`LayoutEditorActivity`):**
    *   Создать отдельный экран, где пользователь может:
        *   Добавлять/удалять виджеты контроллера.
        *   Изменять размеры и позиции (Drag & Drop).
        *   Настраивать логику кнопок (например, "Эта кнопка должна имитировать нажатие клавиши 'Enter'").
    *   Этот экран должен быть полностью отделен от процесса удаленного управления.
2.  **Меню Управления во время сеанса (Back Button Menu):**
    *   При активации Android Back Button во время удаленного управления, вместо стандартного действия должно появляться полупрозрачное меню (Overlay).
    *   Это меню должно содержать:
        *   Переключатель режима ввода (Клавиатура / Мышь / Сенсорный ввод).
        *   Выпадающий список доступных лауаутов для немедленной смены.
3.  **Интеграция в поток:** Обновить главный экран управления, чтобы он использовал `LayoutManager` и был готов к переключению режимов ввода через Back Button Menu.

### Фаза 4: Тестирование и Полировка (Refinement)
1.  Провести комплексное тестирование всех сценариев ввода (переключение между мышью/клавиатурой, нажатие кнопок в разных лауаутах).
2.  Оптимизировать производительность отрисовки контроллера при частых изменениях лауаута.

---
**Следующие шаги:** Начать с Фазы 1 (Улучшение обработки ввода), так как она является фундаментом для всех последующих изменений.
